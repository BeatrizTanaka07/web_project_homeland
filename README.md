# Tripleten web_project_homeland

## Descrição

Página web que mostra as cidades natais de alguns funcionários da TripleTen.

### Funcionalidades

- Site responsivo para as telas entre 1280px, 760px e 320px. (Breakpoints utilizados: 544px e 1024px)

### Tecnologias utilizadas

- HTML: estrutura semântica.
- CSS: estilização.
- Metodologia BEM: padrão de nomenclatura das classes.
- Git: sistema de controle de versão.
- GitHub: plataforma de compartilhamento e publicação.
